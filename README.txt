TIME MGT — مهام اليوم (نسخة الموبايل)

الملفات:
  index.html           التطبيق كله (HTML + CSS + JS)
  manifest.webmanifest + sw.js + icon-*.png   لتثبيته على الموبايل وفتحه بدون نت
  files.json (اختياري) قائمة الـ PDF من تطبيق المكتبة؛ لو حطيتيه جنب index.html بتظهر في إضافة المهمة

التجربة في VS Code:
  1) افتحي الفولدر في VS Code
  2) ثبّتي إضافة Live Server وكليك يمين على index.html ← Open with Live Server
  (لازم سيرفر، لأن الـ Service Worker مش بيشتغل من فتح الملف مباشرة)

على الموبايل:
  ارفعي الفولدر كله على Netlify Drop (أو GitHub Pages) وافتحي الرابط من الموبايل،
  ثم من قائمة المتصفح: "إضافة إلى الشاشة الرئيسية" (Add to Home screen).

ملاحظات:
  - المهام بتتخزن على نفس الجهاز والمتصفح (localStorage)، مش بتتزامن بين الموبايل والكمبيوتر.
  - التذكيرات بتشتغل والتطبيق مفتوح، وبتتفعّل بزر 🔔. التذكير والتطبيق مقفول يحتاج سيرفر.
  - السحب: يمين = تمّت، شمال = حذف (مع زر تراجع).
